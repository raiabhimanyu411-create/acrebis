# ACREBIS.ai

Responsive React and Vite website for the ACREBIS connected retail operations platform.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Project structure

- `src/pages/` — separate route-level page components
- `src/components/` — shared navigation, UI, forms, and visual components
- `src/data/` — shared sitemap and product content
- `src/App.jsx` — routing and global interaction behavior
- `src/main.jsx` — React application entry point
